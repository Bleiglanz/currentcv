\mainhead{Profile}
Systems and network administrator with 25+ years in IT. For the past four years I ran the
process control network (PCN) of a refinery site -- directory services, virtualisation, backup,
switching, firewalls and network monitoring in a 24/7 production environment where
availability and segmentation are non-negotiable. Long background in Linux server and
database administration and in software development, which I use to automate and document
the infrastructure I operate. Used to working independently on site, from switch CLI and
server room to audits, change requests and project delivery.
